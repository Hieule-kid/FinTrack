# FinTrack :: Core — Shared Library

> Shared utilities, base classes, and error-handling infrastructure used by **every** FinTrack microservice.
> This module is **not** a runnable service — it is compiled and packaged as a JAR dependency.

---

## 📦 Module Coordinates

```xml
<dependency>
    <groupId>com.fintrack</groupId>
    <artifactId>core</artifactId>
    <version>1.0.0-SNAPSHOT</version>
</dependency>
```

## 📁 Package Structure

```
com.fintrack.core/
├── base/
│   ├── BaseEntity.java          # @MappedSuperclass — id, audit fields, soft-delete
│   ├── BaseService.java         # Generic CRUD service contract <C, U, R>
│   └── BaseController.java      # Abstract REST controller wiring BaseService → endpoints
├── dto/
│   ├── ApiResponse.java         # Unified JSON envelope for all REST responses
│   └── PageResponse.java        # Pagination wrapper
├── exception/
│   ├── ErrorCode.java           # All application error codes (1xxx / 2xxx / 3xxx / 5xxx)
│   ├── AppException.java        # Runtime exception wrapping an ErrorCode
│   └── GlobalExceptionHandler.java  # @RestControllerAdvice — converts exceptions → JSON
└── utils/
    └── DateUtils.java           # Date/time helpers (UTC, Vietnam TZ, month/week ranges)
```

## 🧱 BaseEntity

**File:** `com.fintrack.core.base.BaseEntity`

All JPA entities in FinTrack extend `BaseEntity`. It provides:

| Field | Type | Column | Description |
|---|---|---|---|
| `id` | `String` | `id` (UUID) | Primary key, generated by the database, immutable |
| `createdAt` | `LocalDateTime` | `created_at` | Auto-set on insert via JPA auditing |
| `updatedAt` | `LocalDateTime` | `updated_at` | Auto-updated on every save via JPA auditing |
| `createdBy` | `String` | `created_by` | User ID who created the row (requires `AuditorAware` bean) |
| `updatedBy` | `String` | `updated_by` | User ID who last modified the row |
| `deleted` | `boolean` | `is_deleted` | Soft-delete flag; always filter by `deleted = false` in queries |

**Soft Delete Convention:**
```java
// ✅ Correct — soft delete
entity.setDeleted(true);
repository.save(entity);

// ❌ Never do this
repository.delete(entity);
```

**Enabling JPA Auditing** in a service:
```java
@SpringBootApplication
@EnableJpaAuditing       // ← required
public class MyServiceApplication { ... }
```

## 📬 ApiResponse\<T\>

**File:** `com.fintrack.core.dto.ApiResponse`

Every endpoint in FinTrack returns this envelope:

```json
{
  "code":      200,
  "message":   "OK",
  "data":      { "...": "..." },
  "timestamp": "2026-07-04T10:00:00"
}
```

`null` fields are omitted from the JSON output (`@JsonInclude(NON_NULL)`).

### Factory Methods

| Method | HTTP Status | Usage |
|---|---|---|
| `ApiResponse.success(data)` | 200 | Standard GET / PATCH responses |
| `ApiResponse.success(data, message)` | 200 | With a custom message (e.g. `"Milestone updated"`) |
| `ApiResponse.created(data)` | 201 | POST — resource created |
| `ApiResponse.error(code, message)` | varies | Error responses from `GlobalExceptionHandler` |

## 📄 PageResponse\<T\>

**File:** `com.fintrack.core.dto.PageResponse`

Returned by paginated list endpoints:

```json
{
  "content":       [ { "id": "..." }, { "id": "..." } ],
  "pageNumber":    0,
  "pageSize":      10,
  "totalElements": 42,
  "totalPages":    5,
  "last":          false
}
```

Build from a Spring Data `Page<T>`:
```java
PageResponse.of(page); // wraps Spring Data Page into FinTrack DTO
```

## ⚠️ Error Codes

**File:** `com.fintrack.core.exception.ErrorCode`

| Code | Constant | HTTP Status | Message |
|------|----------|-------------|---------|
| 1001 | `UNAUTHORIZED` | 401 | Authentication required |
| 1002 | `FORBIDDEN` | 403 | Access denied |
| 1003 | `INVALID_TOKEN` | 401 | JWT token is invalid or expired |
| 1004 | `INVALID_CREDENTIALS` | 401 | Invalid email or password |
| 1005 | `TOKEN_EXPIRED` | 401 | Token has expired |
| 2001 | `RESOURCE_NOT_FOUND` | 404 | Resource not found |
| 2002 | `USER_NOT_FOUND` | 404 | User not found |
| 3001 | `VALIDATION_ERROR` | 400 | Validation failed |
| 3002 | `DUPLICATE_EMAIL` | 409 | Email address is already in use |
| 3003 | `DUPLICATE_USERNAME` | 409 | Username is already taken |
| 3004 | `INVALID_REQUEST` | 400 | Invalid request parameters |
| 5001 | `INTERNAL_SERVER_ERROR` | 500 | An unexpected error occurred |
| 5002 | `SERVICE_UNAVAILABLE` | 503 | Service is temporarily unavailable |

**Convention:** `1xxx` — Auth/Authz · `2xxx` — Not Found · `3xxx` — Validation/Business · `5xxx` — Server

## 💥 AppException

**File:** `com.fintrack.core.exception.AppException`

Throw this from any service layer method to trigger a clean HTTP error response.

```java
// Simplest form — uses default message from ErrorCode
throw new AppException(ErrorCode.USER_NOT_FOUND);

// With a context-specific detail message
throw new AppException(ErrorCode.RESOURCE_NOT_FOUND, "Plan not found with id: " + planId);

// Wrapping a root cause
throw new AppException(ErrorCode.INTERNAL_SERVER_ERROR, cause);
```

`GlobalExceptionHandler` will catch this and return:
```json
{
  "code":    2002,
  "message": "User not found",
  "timestamp": "2026-07-04T10:00:00"
}
```

## 🌐 GlobalExceptionHandler

**File:** `com.fintrack.core.exception.GlobalExceptionHandler`

`@RestControllerAdvice` — automatically active in any service that scans `com.fintrack`:

```java
@SpringBootApplication(scanBasePackages = "com.fintrack") // ← picks up the handler
```

| Exception Type | HTTP | Response |
|---|---|---|
| `AppException` | From `ErrorCode` | `{ code, message }` |
| `MethodArgumentNotValidException` | 400 | `{ code: 3001, data: { "field": "error message" } }` |
| `Exception` (catch-all) | 500 | Generic `{ code: 5001, message: "..." }` — stack trace never exposed |

## 🗓️ DateUtils

**File:** `com.fintrack.core.utils.DateUtils`

Stateless utility class (all methods `static`, not instantiable).

| Method | Returns | Description |
|---|---|---|
| `nowUtc()` | `LocalDateTime` | Current time in UTC |
| `nowVietnam()` | `LocalDateTime` | Current time in `Asia/Ho_Chi_Minh` (UTC+7) |
| `startOfMonth(yearMonth)` | `LocalDateTime` | First moment of the given month |
| `endOfMonth(yearMonth)` | `LocalDateTime` | Last moment (`23:59:59`) of the given month |
| `startOfCurrentMonth()` | `LocalDateTime` | First moment of the current month |
| `endOfCurrentMonth()` | `LocalDateTime` | Last moment of the current month |
| `startOfCurrentWeek()` | `LocalDateTime` | Monday `00:00:00` of the current ISO week |
| `endOfCurrentWeek()` | `LocalDateTime` | Sunday `23:59:59` of the current ISO week |
| `toDateString(dateTime)` | `String` | Format to `yyyy-MM-dd` |
| `parseDate(dateStr)` | `LocalDate` | Parse from `yyyy-MM-dd` |

## 🏗️ BaseService & BaseController (Template)

Used by `service-template` to quickly scaffold full CRUD for a new entity.

### BaseService\<C, U, R\>

```
create(C)              → R          POST   /
update(String id, U)   → R          PUT    /{id}
findById(String id)    → R          GET    /{id}
findAll(page,size,...) → PageResponse<R>  GET /
delete(String id)      → void       DELETE /{id}  (soft)
```

### BaseController\<C, U, R\>

Extends `BaseController` in a concrete controller to auto-expose all 5 CRUD endpoints:

```java
@RestController
@RequestMapping("/api/v1/transactions")
public class TransactionController extends BaseController<
        CreateTransactionRequest,
        UpdateTransactionRequest,
        TransactionResponse> {
    public TransactionController(TransactionService svc) { super(svc); }
}
```
